# Supported Versions

PM Platform is currently in active pre-1.2 development. Support is focused on
the current development and release-candidate line.

## Version Support Matrix

| Version line | Status | Notes |
| --- | --- | --- |
| v1.1.x | Active | Current planning engine stabilization and release-candidate line. |
| v1.0.6 | Maintenance reference | Planning foundation release documentation is retained for traceability. |
| v1.0.5.x | Historical | Platform hardening release history only. |
| v1.0.0 beta and earlier | Historical | Archived release and UAT reference only. |

## Support Policy

- Active development focuses on the latest release-candidate or stabilization
  line.
- Security fixes should target the active line first.
- Historical release notes remain available for audit and traceability.
- Backports are not guaranteed unless explicitly planned.
