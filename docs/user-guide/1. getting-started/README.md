# Getting Started

## Account Access

Users sign in with their email address and password. If an administrator creates
or resets an account with a temporary password, PM Platform prompts the user to
change that password before continuing.

If a user forgets their password, they can use **Forgot Password?** on the sign
in page. The platform shows the same confirmation message whether or not an
account exists for the email address. Valid reset links are short-lived and can
only be used once.
