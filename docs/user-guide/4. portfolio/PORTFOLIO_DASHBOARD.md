# Portfolio Dashboard

## Purpose

Provide an outline for using the PM Platform Portfolio Dashboard.

## Scope

This guide covers portfolio health, projects requiring attention, upcoming milestones, overdue work, open risks, open issues, and executive drilldowns.

## Audience

Executives, PMO leaders, portfolio managers, delivery leaders, and project sponsors.

## Overview

The Portfolio Dashboard gives leaders a consolidated view of project health and delivery risk. It should help users identify projects requiring attention and navigate into supporting project details.

## Contents

### Introduction

Use the Portfolio Dashboard to monitor project health, delivery risk, upcoming milestones, and workload signals across the portfolio.

### Prerequisites

- Active PM Platform account.
- Portfolio or executive visibility permissions.
- Projects with current health, tasks, RAID data, and planning dates.

### Step-by-step Usage

1. Navigate to the Portfolio Dashboard.
2. Review portfolio summary metrics.
3. Inspect projects requiring attention.
4. Review open risks and issues by severity or priority.
5. Review upcoming milestones and overdue task indicators.
6. Drill into a project for detailed context.
7. Use RAID and Planning Workspace views for deeper analysis.

### Troubleshooting

| Issue | Recommended Action |
| --- | --- |
| Project is missing | Confirm portfolio visibility and project access rules. |
| Health status seems stale | Review project tasks, RAID items, and planning dates. |
| Milestones are missing | Confirm milestone tasks have planned dates. |

### FAQ

| Question | Answer |
| --- | --- |
| Does the dashboard show all projects? | It shows projects visible to the current user. |
| Are milestone dates planning-aware? | Planning-aware reporting is evolving with the planning engine roadmap. |
| Can executives drill into RAID details? | Yes, where permissions allow project or RAID visibility. |
