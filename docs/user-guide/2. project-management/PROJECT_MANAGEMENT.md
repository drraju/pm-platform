# Project Management

## Purpose

Provide an outline for using PM Platform project management capabilities.

## Scope

This guide covers project creation, project workspace navigation, team membership, task tracking, project health, and related project-level workflows.

## Audience

Project managers, delivery leads, PMO users, contributors, and executives who need project-level visibility.

## Overview

Project Management is the core workflow for organizing delivery work. Users can review project details, manage project teams, track tasks, inspect planning data, and connect project execution to RAID and portfolio reporting.

## Contents

### Introduction

Use the Project Management area to create and maintain project records, assign ownership, manage team membership, and track delivery execution.

### Prerequisites

- Active PM Platform user account.
- Project access granted by owner, manager, or administrator.
- Required permissions for creating or updating project data.

### Step-by-step Usage

1. Navigate to the Projects page.
2. Select an existing project or create a new project where permitted.
3. Review project summary, ownership, status, dates, and health.
4. Add or update project members.
5. Create and maintain project tasks.
6. Review planning, RAID, and baseline sections as available.
7. Use dashboard links for portfolio or executive visibility.

### Troubleshooting

| Issue | Recommended Action |
| --- | --- |
| Project is not visible | Confirm project membership or visibility permissions. |
| Cannot edit project | Confirm project manager or equivalent permissions. |
| Assignee is unavailable | Confirm the user is an active project member. |
| Health does not match expectation | Review overdue tasks, RAID items, and project status inputs. |

### FAQ

| Question | Answer |
| --- | --- |
| Can contributors edit all project fields? | No. Edit access depends on assigned permissions and project role. |
| Can a project have multiple owners? | Ownership fields support defined leadership roles; team membership captures broader participation. |
| Are project tasks the same as planning schedule rows? | Tasks are execution records; planning schedule rows may be snapshot-backed planning records. |
