# PM Platform v1.0

## Theme

Core Project Management Foundation

## Features

- Project creation and lifecycle management
- Task management
- Team membership
- RAID register
- Kanban-style work tracking
- Executive dashboard
- User dashboard
- Docker-based deployment

## Success Criteria

- Project teams can create and manage projects end to end.
- Tasks, RAID items, and dashboard views are available from a self-hosted deployment.
- Core permissions and project membership workflows support controlled collaboration.
