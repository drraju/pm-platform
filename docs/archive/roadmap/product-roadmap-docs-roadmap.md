# Product Roadmap

## Vision

The PM Platform will become an enterprise-grade, self-hostable project and portfolio management system that combines disciplined project execution with executive visibility and AI-assisted delivery intelligence.

## Mission

Help organizations plan, execute, govern, and report project work with a consistent operating model across teams, portfolios, and leadership layers.

## Target Users

| Persona | Needs |
| --- | --- |
| Project Manager | Planning, RAID, team coordination, reports |
| Delivery Lead | Task execution, blockers, schedule visibility |
| Portfolio Manager | Cross-project health, milestones, resource pressure |
| Executive | Decisions, risks, trends, accountability |
| Customer Success Manager | Customer-facing health and outcomes |
| Administrator | Users, permissions, deployment, audit |

## Target Market

Organizations that need project governance and self-hosted control but want a cleaner experience than heavyweight enterprise PPM tools.

## Competitive Positioning

| Product Class | PM Platform Position |
| --- | --- |
| Microsoft Project | Similar scheduling discipline, simpler integrated workspace |
| Primavera P6 | Enterprise planning concepts without construction-only assumptions |
| Jira | Stronger project governance, RAID, portfolio, and reporting |
| ClickUp/Asana | More enterprise control and self-hosted deployment |

## Release Themes

| Release | Theme | Primary Outcomes |
| --- | --- | --- |
| Beta 3 | Planning and Project Workspace maturity | WBS, task type model, Planning UX, project execution consistency |
| Beta 4 | Advanced scheduling foundation | Critical path, baselines, calendars, dependency maturity |
| Beta 5 | Resource management | Capacity, workload, allocation, resource reports |
| Beta 6 | Portfolio management | Portfolio Gantt, programs, customers, cross-project RAID |
| Future | AI Project Manager | Summaries, recommendations, predictions, natural language search |

## Future Enterprise Roadmap

- Customer and program management.
- Executive reporting packs.
- Audit and compliance reporting.
- SSO and enterprise identity.
- AI-assisted project and portfolio management.
- Kubernetes and high availability deployment options.
