# PM Platform v1.2

## Theme

Portfolio Intelligence

## Features

- Portfolio roadmap views
- Cross-project dependencies
- Portfolio-level milestones
- Schedule health indicators
- RAID trend reporting
- Executive drilldowns

## Success Criteria

- Portfolio leaders can identify schedule, dependency, and RAID exposure across projects.
- Cross-project planning data is visible without duplicating project-level schedule logic.
- Executive reporting supports planning decisions and escalation workflows.
