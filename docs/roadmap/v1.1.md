# PM Platform v1.1 Roadmap

## Theme

Enterprise Planning

## Goals

- Stabilize Planning Workspace for enterprise scheduling workflows.
- Improve Microsoft Project style scheduling parity.
- Prepare Resource Management to depend on reliable schedule data.
- Strengthen baseline, variance, dependency, and calendar foundations.

## Features

| Area | Planned Work |
| --- | --- |
| Project Calendars | Project-level working and non-working day model. |
| Resource Calendars | Resource availability foundation for capacity planning. |
| Resource Management | Resource pools, allocation, workload, and utilization views. |
| Resource Allocation | Project-level allocation records and over-allocation indicators. |
| Baselines UI | Baseline capture, comparison, and review workflows. |
| Variance Analysis | Schedule and baseline variance indicators for reporting. |
| Critical Path Scheduling | CPM validation, float correctness, and critical path visualization. |
| Dependency Maturity | Dependency validation, scheduling recalculation, and lead/lag preparation. |

## Success Criteria

- Microsoft Project parity for core scheduling workflows.
- Resource utilization reports are available for project-level planning.
- Baseline comparison is visible in Planning Workspace and reporting.
- Critical path and float values are explainable and consistent.
- Planning changes remain auditable and transactionally safe.

## Dependencies

- Stable Scheduling Engine.
- Planning Snapshot consistency.
- Dependency validation.
- Baseline data model.
- Resource allocation model.

## Out Of Scope

- Full portfolio-level resource optimization.
- AI-generated project plans.
- Cross-project dependency scheduling.
- Kubernetes production deployment.
