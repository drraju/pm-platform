# Future Roadmap

## Theme

Portfolio Intelligence And AI-Assisted Project Management

## v1.2 Direction

| Area | Direction |
| --- | --- |
| Portfolio roadmap views | Cross-project schedule and milestone visibility. |
| Cross-project dependencies | Model and report dependencies between projects. |
| Portfolio-level milestones | Aggregate release, drop, go-live, and decision milestones. |
| Schedule health indicators | Summarize schedule risk and delivery confidence. |
| RAID trend reporting | Show risk, issue, and dependency trends across projects. |
| Executive drilldowns | Support decision-focused portfolio navigation. |

## Longer-Term Opportunities

| Area | Direction |
| --- | --- |
| Program Management | Group related projects and report program-level health. |
| Customer Delivery | Link projects to customers, implementations, and customer health. |
| Scenario Planning | Compare project, resource, and portfolio alternatives. |
| Portfolio Optimization | Recommend sequencing and resource tradeoffs across projects. |
| AI Project Planner | Generate draft project plans from natural language and templates. |
| AI Risk Advisor | Detect likely delivery risks from schedule and RAID signals. |
| AI Executive Assistant | Draft status reports, decision briefs, and portfolio summaries. |
| Enterprise Deployment | Add high-availability and Kubernetes deployment options. |

## Success Criteria

- Portfolio leaders can identify schedule, dependency, and RAID exposure across projects.
- Executives can drill from portfolio indicators into project evidence.
- AI recommendations remain explainable, permission-aware, and auditable.
- Future capabilities build on the same planning and scheduling authority.
