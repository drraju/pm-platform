# Beta 4 Roadmap

## Objective

Beta 4 introduces advanced scheduling and resource foundations after Beta 3 stabilizes the planning model and workspace experience.

## Planned Features

| Area | Features |
| --- | --- |
| Resources | Capacity, allocation, workload snapshots, over-allocation indicators |
| Portfolio | Portfolio dashboard expansion, program/customer grouping foundations |
| Advanced Scheduling | Dependency validation, lead/lag preparation, scheduling recalculation |
| Critical Path | Critical path calculation, float fields, critical styling |
| Baselines | Baseline comparison, variance indicators, report output |
| Calendars | Project calendar, working/non-working days, holiday exceptions |

## Critical Path

Critical path should calculate project-critical tasks and milestones based on dependencies, dates, duration, and calendars. It should expose total float and free float for reporting and Gantt rendering.

## Baselines

Baselines should preserve approved schedule state and support variance reporting against current plan.

## Calendars

Calendars should become the foundation for business-day duration, milestone placement, resource availability, and future timesheets.

## Beta 4 Exit Criteria

- Critical path visible in Planning.
- Baseline comparison available for project reports.
- Resource capacity model available for project-level workload.
- Calendar-aware scheduling rules designed and partially implemented.
