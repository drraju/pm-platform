# Engineering Documentation

The Engineering folder contains documentation used to build, test and maintain the PM Platform.

These documents answer **how the platform is developed**.

---

## Contents

Typical documents include:

* Build Playbook
* Development Standards
* Coding Standards
* Testing Strategy
* Deployment Guide
* Docker Guide
* Installation Guide
* Technical Debt Register

---

## Intended Audience

* Developers
* QA Engineers
* DevOps Engineers
* AI Coding Assistants

---

## Objectives

Engineering documentation promotes:

* Consistent implementation
* Repeatable builds
* Reliable testing
* Deployment automation
* Long-term maintainability

Engineering documentation evolves continuously as development practices mature.
