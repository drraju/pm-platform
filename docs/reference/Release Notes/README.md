## v1.0.0-beta2 Summary

This beta validates the current project execution, portfolio visibility, RAID governance, and Planning Workspace experience.

### Highlights

| Area | Summary |
| --- | --- |
| Planning Workspace | Gantt-style timeline, planning grid, inline editing, Add Task, Add Child, dependencies, drag scheduling, resize scheduling, zoom controls, Today, Fit to Project, task reorder, and WBS renumbering. |
| Projects | Project list, filters, health sorting, create, edit, delete, and project workspace navigation. |
| Project Workspace | Overview, health, plan grid, baselines, team management, and project-scoped RAID tabs. |
| Tasks | My Tasks, all-visible task scope, filters, status updates, percent complete, remarks, and reassignment. |
| RAID | Risks, assumptions, issues, and dependencies with create, update, delete, comments, ownership, and project association. |
| Dashboards | Personal dashboard, executive dashboard, and portfolio summaries with drilldowns. |
| Infrastructure | Docker deployment files, environment configuration, PostgreSQL backend, and development scripts. |
