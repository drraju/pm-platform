# v1.0.5.6.1 Executive Dashboard Drilldown Alignment

Date: 2026-06-20

## Summary

v1.0.5.6.1 corrects executive and portfolio landing behavior, aligns executive dashboard drilldowns with globally visible datasets, and preserves dashboard-driven filters through URL parameters so widget totals match the resulting list views.

This release does not add or modify Timeline or Gantt behavior.

## Changes Delivered

| Area | Change |
| --- | --- |
| Default landing | `Executive` users now land on `/executive` after sign-in and when opening `/dashboard`. `Portfolio Manager` users now land on `/portfolio`. |
| Executive drilldowns | Executive dashboard cards now drill into globally visible filtered datasets instead of user-scoped lists. |
| Count alignment | Open risk, open issue, overdue task, and project health drilldowns now use filters that match the dashboard summary counts. |
| URL preservation | Project and task filter state now round-trips through URL parameters so refresh, deep links, and drilldowns preserve the active view. |
| Regression coverage | Added tests for login landing, executive drilldown links, open RAID drilldowns, overdue task filtering, and project health drilldown filters. |

## Drilldown Mapping

| Widget | Previous behavior | Corrected behavior |
| --- | --- | --- |
| Executive login/dashboard | Routed to `/dashboard` | Routes to `/executive` for `Executive` |
| Portfolio Manager login/dashboard | Routed to `/dashboard` | Routes to `/portfolio` for `Portfolio Manager` |
| Green / Amber / Red Projects | Filter not preserved consistently | `/projects?health=<STATUS>&sort=<health sort>` |
| Open Risks | Linked to a severity-specific view | `/risks?status=open` |
| Open Issues | Linked to a priority-specific view | `/issues?status=open` |
| Overdue Tasks | Already global, but date filtering drifted | `/tasks?scope=all&timing=overdue` with date-only comparison aligned to backend counting |
