# v1.0.5.8 Modal and Form Usability Hardening

Date: 2026-06-13

## Summary

v1.0.5.8 introduces a shared responsive modal shell and applies it to long-running PM Platform forms. The Task and RAID forms now keep Save and Cancel actions visible while the form body scrolls inside the modal.

## Root Cause

UAT found that Create Task, Edit Task, Reassign Task, and long remarks fields could exceed the viewport. The root cause was the previous modal structure:

- The entire form sat inside a centered panel.
- The panel did not consistently enforce `max-height`.
- Header, body, and footer were not separated.
- Save and Cancel buttons lived at the bottom of the form content, so they moved below the visible viewport when forms were long.

## Shared Modal Implementation

Added:

- `frontend/components/ui/app-modal.tsx`

Modal behavior:

- `max-h-[90vh]`
- `overflow-hidden` modal panel
- scrollable body via `overflow-y-auto`
- sticky header
- sticky footer
- Escape key closes the modal
- mobile-friendly padding and width constraints
- stable test ids for viewport usability tests

## Usability Guarantees

- Save button remains outside the scrollable body.
- Cancel button remains outside the scrollable body.
- Remarks and long text fields scroll inside the modal body.
- Modal height remains capped at 90 percent of the viewport.
- Header and footer remain pinned while scrolling.
- Escape closes the active modal.
