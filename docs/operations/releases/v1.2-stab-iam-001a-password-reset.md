# v1.2 STAB-IAM-001A Password Reset

## Summary

STAB-IAM-001A completes the v1.2 password reset workflow using the existing
authentication architecture.

## Added

- `POST /auth/forgot-password` accepts an email address and returns a generic
  success response without exposing account existence.
- `POST /auth/reset-password` accepts a reset token and new password, validates
  token expiry and single-use status, applies the existing password policy, and
  updates the user's password timestamp.
- Forgot Password and Reset Password frontend pages are available from the
  authentication flow.

## Security Notes

- Reset tokens are generated with cryptographically secure randomness.
- Only SHA-256 token hashes are stored in PostgreSQL.
- Reset tokens expire after a short window and are consumed after successful
  password reset.
- Password changes continue to invalidate older JWTs through
  `password_changed_at` validation.

## Out Of Scope

Refresh-token persistence, token rotation, device/session management, password
history, account lockout, MFA, and broader authentication redesign are deferred
to v1.3.
