# v1.0.6 Phase 4.2 Enterprise Planning Usability

Review date: 2026-06-19

## Summary

This change implements the Phase 4.2 UAT follow-up for enterprise planning usability.

It improves drilldown reliability for executive and portfolio reporting, aligns contributor navigation with seeded enterprise roles such as `Engineer` and `QA Engineer`, and updates planning terminology so the UI uses enterprise-facing labels without changing the approved backend planning model.

## Delivered

- fixed executive and portfolio overdue-task drilldowns so they navigate to an all-visible filtered task list instead of a self-scoped task view
- normalized destination page filters so incoming drilldown values are honored consistently:
  - project health
  - risk severity
  - issue priority
  - task timing and scope
- retained permission-based navigation while explicitly validating the seeded `Engineer` contributor experience
- updated Project Workspace planning terminology:
  - `Phase` for summary task UI
  - `Task` for work item UI
  - `Milestone` for checkpoint UI
- updated planning help text and architecture/testing documentation to reflect enterprise planning terminology

## Scope Boundaries

This phase does not implement:

- Timeline UI
- Gantt UI
- backend planning model changes
- new dependency or baseline backend endpoints

## Notes

- the persisted domain model still uses `task_kind = summary`
- API contracts remain unchanged and continue to use `summary`
- the `Phase` label is a presentation-layer terminology refinement only
- the all-visible tasks drilldown reuses the existing `GET /tasks` API
