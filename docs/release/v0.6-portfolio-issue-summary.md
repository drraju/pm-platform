# v0.6 Portfolio Issue Summary

Release Date: YYYY-MM-DD

## Overview

This release extends the Portfolio Dashboard with issue-level portfolio visibility, enabling programme managers and PMOs to quickly assess issue exposure across all active projects.

The dashboard now provides consolidated views of:

* Portfolio Health
* Projects Requiring Attention
* Open Risks by Severity
* Open Issues by Priority

## Features Added

### Portfolio Issue Summary

Added a new Portfolio Dashboard widget:

Open Issues by Priority

The widget displays:

* Critical Issues
* High Priority Issues
* Medium Priority Issues
* Low Priority Issues

This provides a portfolio-wide view of issue concentration and helps leadership teams identify projects requiring immediate intervention.

### Portfolio API Enhancements

Extended:

GET /portfolio/summary

to return:

```json
{
  "openIssuesByPriority": {
    "critical": 0,
    "high": 0,
    "medium": 0,
    "low": 0
  }
}
```

The aggregation is calculated centrally within the Portfolio Service.

### Portfolio Governance Improvements

Portfolio reporting now supports:

* Project Health Visibility
* Risk Exposure Visibility
* Issue Exposure Visibility

These metrics form the foundation for future executive dashboards and governance reporting.
