# v0.7 Portfolio Overdue Tasks

Release Date: YYYY-MM-DD

## Overview

This release extends the Portfolio Dashboard with portfolio-wide visibility of overdue work.

Programme managers, PMOs, and delivery leaders can now quickly identify delivery slippage across active projects and determine which projects require intervention due to overdue tasks.

The Portfolio Dashboard now provides visibility into:

* Portfolio Health
* Projects Requiring Attention
* Open Risks by Severity
* Open Issues by Priority
* Overdue Tasks

## Features Added

### Portfolio Overdue Tasks

Added a new Portfolio Dashboard widget:

Overdue Tasks

The widget provides:

* Total Overdue Tasks
* Projects with Overdue Tasks
* Direct navigation to affected project workspaces

This enables proactive monitoring of delivery performance across the portfolio.

### Portfolio API Enhancements

Extended:

GET /portfolio/summary

to return:

```json
{
  "overdueTasks": {
    "total": 0,
    "projects": []
  }
}
```

Each project entry contains:

```json
{
  "projectId": "",
  "projectName": "",
  "overdueTaskCount": 0
}
```

### Delivery Governance Improvements

Portfolio reporting now supports:

* Project Health Visibility
* Risk Exposure Visibility
* Issue Exposure Visibility
* Delivery Performance Visibility

Overdue task monitoring provides an early warning indicator for schedule slippage and supports portfolio-level governance reviews.
