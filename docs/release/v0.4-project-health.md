### Project Health Engine

Project health evaluation introduced.

* Green
* Amber
* Red

Health is calculated from:

* Open risks
* Critical issues
* Task delivery indicators

* Health badge
* Health reasons

* Improved dashboard response contracts
* Dashboard health integration
