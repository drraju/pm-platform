# Keyboard Shortcuts

PM Platform does not currently implement app-wide custom keyboard shortcuts.

The application does support standard browser keyboard navigation and a small set of contextual keyboard interactions in the Planning Workspace inline editor. The items below reflect behavior present in the current implementation.

## App-wide Shortcuts

| Shortcut | Status |
| --- | --- |
| Custom global shortcuts | Not implemented |

## Standard Browser Navigation

| Action | Keyboard interaction |
| --- | --- |
| Move through links, buttons, inputs, and menus | `Tab` / `Shift+Tab` |
| Activate a focused link or button | `Enter` |
| Activate a focused button | `Space` |
| Change a focused select control | Arrow keys, then `Enter` |
| Change a focused checkbox or toggle | `Space` |

## Planning Workspace Inline Editing

| Action | Keyboard interaction |
| --- | --- |
| Select a focused planning row | `Enter` or `Space` |
| Commit an inline edit | `Enter` |
| Cancel an inline edit | `Esc` |
| Commit an inline edit and move to the next editable cell | `Tab` while editing |

## Current Limitations

- Gantt bar drag scheduling is mouse-driven.
- Gantt bar resize is mouse-driven.
- Planning row reorder is mouse-driven.
- Keyboard alternatives for advanced Gantt and row reorder operations are planned accessibility improvements.
