# About PM Platform

PM Platform is a self-hosted enterprise project management platform for project execution, portfolio visibility, planning, task management, and RAID governance.

## Product Summary

| Area | Description |
| --- | --- |
| Product | PM Platform |
| Architecture | Next.js frontend, NestJS backend, TypeScript, PostgreSQL, Docker deployment support |
| Primary users | Project Managers, Program Managers, Delivery Leads, Technical Leads, Engineers, QA Engineers, Product Owners |
| Core domains | Projects, tasks, planning, RAID, dashboards, portfolio, users, permissions |

## Current Beta Focus

- Project and portfolio visibility.
- Project Workspace execution workflows.
- Task management and contributor updates.
- RAID governance across risks, assumptions, issues, and dependencies.
- Planning Workspace foundation with Gantt-style scheduling controls.
- Role-based navigation and permissions.
- Docker-based deployment validation.

## Roadmap Direction

| Area | Direction |
| --- | --- |
| Planning | Stabilize schedule calculations, dependency validation, critical path, and performance. |
| Resource Management | Add capacity planning, allocations, utilization views, and leveling workflows. |
| Portfolio Planning | Add cross-project dependencies, roadmap views, and scenario planning. |
| Integrations | Implement Slack and Google Drive workflows beyond current backend shells. |
| Notifications | Add notification delivery, read state, and event-driven alerts. |
| AI Project Manager | Explore AI-assisted planning, risk detection, status summarization, and delivery recommendations. |
