# v1.0.5 Project Teams & Task Operations

## Features

- Added project team management APIs and workspace controls for adding, updating, and removing project members.
- Added task operation fields for remarks, percent complete, planned dates, and actual dates.
- Enhanced My Tasks with inline status, remarks, percent complete, and reassignment updates.
- Enforced project/task operation policy for program managers, project managers, project owner/manager members, and assigned team members.

## Database Changes

- Added migration: `backend/src/database/migrations/002_v1_0_5_project_teams_task_operations.sql`.
- Added `tasks.remarks`.
- Added `tasks.percent_complete` with `0..100` constraint.
- Added `tasks.planned_start_date`.
- Added `tasks.planned_end_date`.
- Added `tasks.actual_start_date`.
- Added `tasks.actual_end_date`.
- Seed data now creates v1.0.5 permissions and assigns them to seeded roles.

## APIs

- `GET /projects/:id/members`
- `POST /projects/:id/members`
- `PATCH /projects/:id/members/:memberId`
- `DELETE /projects/:id/members/:memberId`
- `GET /projects/:projectId/tasks`
- `POST /projects/:projectId/tasks`
- `PATCH /projects/:projectId/tasks/:taskId`
- `DELETE /projects/:projectId/tasks/:taskId`
- `PATCH /tasks/:id`

For backward compatibility, member update/delete lookup accepts either the project membership id or the older user id value.

## Permissions

- `project.team.manage`
- `task.create`
- `task.update`
- `task.delete`
- `task.reassign`
- `task.comment`

Program Manager, Project Manager, and project owner/manager members can manage project teams and full task operations. Assigned team members can update their own task status, remarks, percent complete, and assignee, with reassignment restricted to users already on the project team.
