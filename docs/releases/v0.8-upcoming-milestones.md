# v0.8 Upcoming Milestones

Release Date: YYYY-MM-DD

## Overview

This release extends the Portfolio Dashboard with visibility into upcoming delivery milestones.

Portfolio leaders can now proactively monitor upcoming work across projects and identify near-term delivery commitments.

The Portfolio Dashboard now provides visibility into:

* Portfolio Health
* Projects Requiring Attention
* Open Risks by Severity
* Open Issues by Priority
* Overdue Tasks
* Upcoming Milestones

## Features Added

### Upcoming Milestones

Added a new Portfolio Dashboard widget:

Upcoming Milestones

The widget displays:

* Milestone Title
* Project Name
* Due Date

Milestones are derived from existing project tasks and require no additional database entities.

### Portfolio API Enhancements

Extended:

GET /portfolio/summary

to return:

```json
{
  "upcomingMilestones": [
    {
      "taskId": "",
      "title": "",
      "projectId": "",
      "projectName": "",
      "dueDate": ""
    }
  ]
}
```

### Portfolio Planning Improvements

Portfolio reporting now supports:

* Health Monitoring
* Risk Monitoring
* Issue Monitoring
* Delivery Monitoring
* Forward-Looking Milestone Visibility

This enables leadership teams to identify upcoming delivery commitments before they become overdue.
