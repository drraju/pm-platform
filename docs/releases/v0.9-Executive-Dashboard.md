# v0.9 Executive Dashboard

Release Date: YYYY-MM-DD

## Overview

This release introduces the Executive Dashboard, providing a consolidated leadership view of portfolio performance, delivery status, governance indicators, and projects requiring attention.

The Executive Dashboard serves as the primary landing page for PMO leaders, programme managers, portfolio managers, and executive stakeholders.

The dashboard aggregates data from existing project, task, risk, issue, health, and portfolio services into a single executive reporting experience.

## Features Added

### Executive Dashboard

Added a new Executive Dashboard page:

/executive

The dashboard provides a consolidated view of:

* Portfolio Health
* Delivery Status
* Governance Status
* Projects Requiring Attention

### Portfolio Health Summary

Added executive-level portfolio health indicators:

* Total Projects
* Green Projects
* Amber Projects
* Red Projects

These metrics provide an immediate view of overall portfolio performance.

### Delivery Summary

Added delivery indicators:

* Overdue Tasks
* Upcoming Milestones

These metrics provide visibility into delivery execution and upcoming commitments.

### Governance Summary

Added governance indicators:

* Open Risks
* Open Issues

These metrics provide visibility into portfolio-level risk and issue exposure.

### Projects Requiring Attention

Added a dedicated executive attention section displaying:

* Project Name
* Health Status
* Health Reasons

Projects identified as Amber or Red are surfaced automatically to support governance reviews and escalation management.

Project names link directly to the Project Workspace.

### Executive API

Added:

GET /executive/summary

The endpoint aggregates executive reporting metrics from existing portfolio services.

Example:

```json id="1a5r7v"
{
  "portfolioHealth": {
    "totalProjects": 3,
    "greenProjects": 1,
    "amberProjects": 1,
    "redProjects": 1
  },
  "delivery": {
    "overdueTasks": 0,
    "upcomingMilestones": 10
  },
  "governance": {
    "openRisks": 10,
    "openIssues": 5
  }
}
```
