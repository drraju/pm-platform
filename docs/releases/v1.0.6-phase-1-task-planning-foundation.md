# v1.0.6 Phase 1 Task Planning Foundation

## Summary

This change implements Phase 1 of the `v1.0.6` planning foundation.

Delivered in this phase:

- `parent_task_id`
- `task_kind`
- `sequence_number`
- hierarchy validation
- milestone validation

Deferred from this phase:

- dependencies
- baselines
- timeline APIs and UI
- Gantt APIs and UI

## Scope Delivered

### Task Model

The task model now supports:

- parent-child task hierarchy
- task kind classification:
  - `standard`
  - `summary`
  - `milestone`
- sequence ordering for future WBS and planning grid usage

### Validation Rules

The backend now enforces:

- same-project parent-child task relationships
- no self-parenting
- no hierarchy cycles during parent reassignment
- only summary tasks may contain child tasks
- milestones must have matching planned start and planned end dates when both are present

## Notes

- This phase introduces the minimum domain foundation for future planning work.
- No dependency model is added yet.
- No baseline model is added yet.
- No timeline or Gantt rendering is added yet.
