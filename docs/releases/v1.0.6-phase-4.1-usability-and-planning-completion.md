# v1.0.6 Phase 4.1 Usability and Planning Completion

Review date: 2026-06-19

## Summary

This change completes the Phase 4.1 UAT follow-up for the `v1.0.6` planning foundation.

It improves planning usability in the Project Workspace, closes the biggest planning workflow gaps left after Phase 4, and adds real drilldowns from dashboard reporting surfaces.

## Delivered

- tightened task assignment and reassignment UI behavior:
  - Program Manager, Project Manager, and Delivery Lead retain assignment controls
  - Team Members remain limited to updating their own assigned tasks
- added dependency management inside the Plan workspace:
  - create
  - view
  - edit
  - delete
- added a Baselines tab in the Project Workspace
- added baseline capture from the workspace
- added baseline snapshot history and current-vs-baseline variance display
- added logged-in user identity in the shell header:
  - display name
  - role
  - avatar initials
- added drilldowns from:
  - user dashboard summary cards and work lists
  - executive dashboard widgets
  - portfolio dashboard widgets
  - project workspace summary cards
- added filtered list support for drilldown destinations:
  - projects
  - tasks
  - risks
  - issues

## Scope Boundaries

This phase does not implement:

- Timeline UI
- Gantt UI
- Critical Path UI
- scheduling automation
- drag-and-drop planning

## Notes

- dependency CRUD uses the existing Phase 2 project dependency APIs
- baseline capture uses the existing Phase 3 baseline API, with added baseline read endpoints for viewer support
- baseline snapshots remain immutable and historically self-contained
- WBS remains derived in the UI and is not stored as an authoritative hierarchy code

## Validation

Verified with:

- focused frontend tests for:
  - plan workspace
  - project API client
  - app shell
  - portfolio page
  - project navigation and CRUD pages
- frontend production build
