# v1.0.6

## Purpose

Summarize the v1.0.6 planning foundation release.

## Scope

This release document covers objectives, features, architecture changes, database changes, known issues, and future work for the planning foundation milestone.

## Audience

Product managers, engineers, QA engineers, release managers, PMO stakeholders, and implementation teams.

## Overview

v1.0.6 established the planning foundation for PM Platform by extending project tasks with planning semantics, dependencies, hierarchy, baselines, and project workspace usability improvements. It prepared the platform for the v1.1 planning workspace and later enterprise scheduling capabilities.

## Contents

### Objectives

- Introduce task planning fields.
- Support task hierarchy and milestone semantics.
- Model task dependencies.
- Capture project baselines.
- Improve project workspace planning usability.
- Preserve project authorization and visibility rules.

### Features

| Feature | Summary |
| --- | --- |
| Task planning fields | Planned dates, actual dates, percent complete, task kind, and sequence support. |
| Hierarchy | Summary tasks can contain child tasks. |
| Milestones | Milestone tasks represent zero-duration checkpoints. |
| Dependencies | Task-to-task dependency model with dependency type and lag. |
| Baselines | Project baseline capture for schedule comparison. |
| Workspace usability | Improved project workspace sections for planning review. |

### Architecture Changes

- Extended task model for planning semantics.
- Added task dependency model.
- Added project baseline and baseline task model.
- Strengthened project-scoped validation rules.

### Database Changes

- Added planning-related columns to tasks.
- Added `task_dependencies`.
- Added `project_baselines`.
- Added `project_baseline_tasks`.
- Added indexes for planning and baseline access patterns.

### Known Issues

- Full Gantt scheduling was not part of the initial foundation.
- Critical path calculation was deferred.
- Resource capacity planning remained out of scope.
- Cross-project dependencies remained future work.

### Future Work

- Planning Workspace UI.
- Critical path and float calculations.
- Resource Management.
- Portfolio planning and cross-project dependencies.
- Performance hardening for large plans.
