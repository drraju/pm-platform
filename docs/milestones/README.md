# Milestones

Build these in order. One milestone is one slice a person can use. Do not start the next file until the current acceptance checks pass on the running app.

Shared rules live in [principles](../product/principles.md), [roles and access](../product/roles-and-access.md), [shared objects](../product/shared-objects.md), and the [information architecture](../product/information-architecture.md). The reason for the sequence is the [audit](../audit/2026-10-29-startup-readiness.md).

| # | Milestone | A person can… |
| --- | --- | --- |
| 01 | [Identity and roles](M01-identity-and-roles.md) | Sign in with Google or a local account, and hold more than one role |
| 02 | [Shell](M02-shell.md) | See only working menu rows, and land in the right room |
| 03 | [Customers](M03-customers.md) | Keep one customer list for sales, success, and delivery |
| 04 | [Projects](M04-projects.md) | Open a project for a customer, and make a lead the manager of that project |
| 05 | [Today](M05-today.md) | Update work once and see the same overdue count everywhere |
| 06 | [Plan](M06-plan.md) | Schedule those work items inside the project |
| 07 | [Board](M07-board.md) | Move the same items across four columns |
| 08 | [Customer Success](M08-customer-success.md) | Open a Success section that reads the customer and the project |
| 09 | [Notifications](M09-notifications.md) | Hear about a blocked or overdue item they own |
| 10 | [Slack](M10-slack.md) | Get that same event in a channel the project chose |
| 11 | [Programs and executives](M11-programs-and-executives.md) | Read a program using the same numbers as Today |
| 12 | [Sales handoff](M12-sales-handoff.md) | Turn a prospect into a customer and ask for a project |
| 13 | [Search](M13-search.md) | Find a customer, project, or work item from anywhere |
| 14 | [External customers](M14-external-customers.md) | Let a customer see their project and nothing internal |

RAID, forecast, baseline, resource leveling, the AI playground, and enterprise calendars are not in this queue. Leave them out of the menu.
