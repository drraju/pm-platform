# PM Platform

Enterprise project, portfolio, planning, and RAID management platform built with NestJS, Next.js, TypeScript, and PostgreSQL.

## Documentation

The project documentation is organized in the [Documentation Index](docs/README.md).

Start there for architecture notes, development workflow, user guides, release summaries, and product planning references.

## Repository Areas

| Area | Description |
| --- | --- |
| `backend/` | NestJS API, domain modules, TypeORM entities, and backend tests. |
| `frontend/` | Next.js application, feature modules, shared components, and frontend tests. |
| `docs/` | Product, architecture, development, release, and user-guide documentation. |
| `docker-compose.yml` | Local Docker deployment entrypoint. |

## Technology Stack

- NestJS and TypeScript for the backend API.
- Next.js, React, and Tailwind CSS for the frontend.
- PostgreSQL for persistence.
- Docker Compose for local deployment.
